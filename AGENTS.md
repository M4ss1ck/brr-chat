# brr-chat

Data-saving social network for groups and DMs on slow, metered connections. Start with
`README.md`, `docs/PROTOCOL.md`, and `docs/adr/`.

## Agent skills

### Issue tracker

Issues live in GitHub Issues for M4ss1ck/brr-chat, via `gh`. See `docs/agents/issue-tracker.md`.

### Triage labels

Default five-role vocabulary (needs-triage, needs-info, ready-for-agent, ready-for-human, wontfix). See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: root `GLOSSARY.md` plus `docs/adr/`. See `docs/agents/domain.md`.
